Meta analysis is a method for summarizing and integrating results from several sources (studies, articles, ...). It is used in clinical research to combine available information on a treatment. We need to take into account variability added by different sources, otherwise we could just add all the values up and gain nothing. We usually do meta analysis using hierarchical models. More on hierarchical models, here: [Multilevel & Hierarchical Models](Multilevel%20&%20Hierarchical%20Models.md).
